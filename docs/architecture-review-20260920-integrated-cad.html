Use names, numbers, units, status dots and selectable rows in the primary dashboard. Do not port MetricPanel's explanatory paragraphs into captions or data fields. Provenance and algorithm details belong in retained evidence or a dedicated metadata view. Numeric nulls and execution states remain explicit.

Higher-order work deferred: a shared selection graph across XYZ, UV, assemblies and fitted primitives; persistent layouts; diagnostic-only streaming; browser-selected operation submission; large-model binary transport. UV camera motion is not the same as XYZ camera motion: link entity selections through correspondence, not camera coordinates. Source/candidate selections require explicit edit maps; equal numeric IDs are insufficient.

The current Gradio inspector has EVENTS = [] and returns no input from preprocess. Local Svelte composition can share selection now; driving Python operations or separately mounted Gradio components requires a later event/value seam with server-side revision and entity validation.

Suggested integration order

  1. Polygonal result projection. Feed an existing host audit into the adopted inspector, preserving checks, source/candidate behavior and retained artifacts. Use existing schemas and tests where possible.
  2. Dashboard recomposition. Separate metric/entity/trace presentation and centralize browser inspection state. Keep the two parent reporting components intact.
  3. Native display identity. Retain triangle-to-face mapping and introduce native-edge selection. Verify mapping across copied shapes and display tessellation.
  4. Revision and capability evolution. Distinguish diagnostic updates from geometry changes; decide the richer scene representation before assemblies or vertex fields are integrated.
  5. Surface/UV vertical slice. Begin with surface analysis and chart computation, then selected topology edits. Join XYZ and UV through explicit correspondence.
  6. Feature/reconstruction vertical slice. Retain intermediate arrays and project feature fields, primitive membership and fit results; keep NURBS evaluation independently callable.
  7. Export integration. Add shared translator coordination before concurrent mixed-workflow export and map actual publication to the host release inventory.

Top recommendation

Result-to-display projection is the strongest first move. It connects existing backend computations to the working Svelte inspector, preserves the parent architecture, and establishes identity and result ownership needed by the later surface and reconstruction modules. It delivers a usable vertical slice before the broader backend extraction.
